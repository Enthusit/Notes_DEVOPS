## 🎓 Concepts Understood

### Token Lifecycle
```
Login → Get Token → Store → Inject in Requests → Expires → Clear & Logout
```

### Request Flow
```
User Action → React State → API Call → Backend → Database → Response → Re-render
```

### Protected Routes
```
Access /notes → Check Token → If Valid: Show Page → If Invalid: Redirect to Login
```

### Error Handling
```
API Error → Catch → Show User Message → Allow Retry
```
